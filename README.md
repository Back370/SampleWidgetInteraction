# SampleWidgetInteraction

An Android application demonstrating advanced animated home screen widgets with AI integration and sensor responsiveness.

## Features

- Animated character widgets with configurable frame rates
- Multi-modal interaction (taps, shake detection, orientation changes)
- AI content generation using Google Gemini
- Intelligent image management and caching
- Sensor integration for gesture detection

## Setup

This project requires Android SDK to be configured for building and running lint checks.
